# Game Systems

Each of these game systems is intentionally kept simple and flexible, while shaping play around the thematic character of the Dusklight setting.

## Work In Progress

I think it's important to preface this with a personal note that everything in here is a work in progress. While I'm pretty confident in the design I'm starting with, these documents may evolve as the first few games in the system and setting are played. Keep in mind we're all here to celebrate the player characters story. 

While healthy discussion about game rules at the table can help to inform the ongoing development of the system, rules lawyering should be avoided and the Keeper holds the ultimate say at the table.

## Story Over Rules

Dusklight is intentionally kept as a rules-light system to allow for more flexible storytelling. While it's important for player actions to have consequences, and limits need to be in place to make the game a challenge, in general it's okay to play by the rule of cool. If you think something should work, and the Keeper OKs it, that's within bounds, even if these docs say otherwise.
