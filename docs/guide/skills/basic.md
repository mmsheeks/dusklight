# Basic Skills

All characters start off with these basic skills. These are the sorts of things a common adventurer might know, they make you good at surviving in the wilderness, not necessarily at fighting off hordes of zombies. Still, these are what set your standard adventurer apart from a common citizen, and you can improve them over time.

All basic skills start at level 1.

!!! note
    this list is very much still a work in progress. expect there to be more by the time the first game is played.

## Practiced Fitness

You made a practice of keeping your body in at least basic good shape. You might not be winning any body building championships anytime soon, but if you had to run a mile unexpectedly you'd be okay. Might even win the race.

This skill grants +1 to strength per level and levels up when your character performs feats of strength or endurance. Can be trained in downtime.

## Wilderness Survival

You're no stranger to what it means to make camp in unfavorable conditions, and you know how to spot a safe place to rest when you need to, if there is one.

This skill grants a +1 to checks when made to survive the natural world per level. This skill levels up gradually based on encounters and travel. Can be trained in downtime.
