# Development Roadmap

This page goes over where I'm currently at in building both the setting and game systems of Dusklight. Keep in mind that this is only as accurate as the last time I thought to update it, but it should give you a general idea of where I'm at and what I think I've got left to do.

It's worth noting that much of what already exists in the [Compendium](../compendium/index.md) wasn't planned when I started this project, so this roadmap has a tendency to grow before things get crossed off.
